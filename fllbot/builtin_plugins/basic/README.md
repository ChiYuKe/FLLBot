# basic

提供 FLLBot 的基础命令。

| 命令 | 说明 |
| --- | --- |
| `/ping`（`/在吗`、`/pong`） | 连通性测试，回复 `pong` |
| `/echo <内容>`（`/复读`、`/repeat`） | 原样复读内容 |
| `/help`（`/帮助`、`/菜单`、`/commands`） | 列出当前可用命令 |
| `/plugins`（`/插件`） | 显示已加载插件及状态 |


## 插件包维护

元信息以 [plugin.toml](plugin.toml) 为准，开发约定见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)，更新记录见 [CHANGELOG.md](CHANGELOG.md)。
