# 变更记录

## 0.11.0

- `send_text_file` 新增 `target_bytes`：只追加注释或空行把文件补到指定字节数（最大 2 MiB），
  用于“生成 1 MB 的 fault.cpp”这类指定大小的测试文件；原内容不变，目标小于原文时不截断。

## 0.10.0

- 新增 `send_text_file`：把代码或文本原样保存为附件发送，支持常见源码/配置扩展名，最多 30000 字符 / 2 MiB。
- 文件扩展名使用白名单，拒绝可执行文件、启动器、压缩包和隐藏文件名；仍声明 `qq.send` 能力，自动参与时由沙盒拒绝。

## 0.9.0

- 架构图接入 ELK.js 0.12.1，使用成熟的 compound graph 布局和边标签定位，移除自写布局与路由。
- 参照 beautiful-mermaid 的简洁视觉，改为米白背景、直接箭头、圆滑连线和独立主副标题。
- 目录树参照 Primer TreeView，改为紧凑文件列表、目录图标与统一缩进，去掉大卡片和装饰性英文标题。
- 架构图新增本地 Node.js 18+ 运行要求；引擎随包附带，运行时不使用浏览器或网络。

## 0.8.0

- 新增 `render_image(format=tree)` 专用目录树排版，独立绘制层级线、文件名和说明；树形文本代码块自动识别。
- 架构图改用浅色卡片与白底节点，纵向分组每行最多三个节点，长标识符增加可用宽度。
- 正交连线搜索避开节点及分组标题，标签避开节点与其他标签，补齐直线边标签。
- 增加结构树、避障与分组折行回归，以及两类可重绘预览图。

## 0.7.0

- 新增 `text__render_diagram`：把 Mermaid flowchart 子集绘制成 PNG 架构图并发送到当前会话。
- 支持 TD/LR 方向、矩形/圆角/判断/数据库节点、实线/虚线/粗线与边标签、subgraph 分组（可嵌套）。
- 节点全部位于 subgraph 时按分组顺序分层排布，适合系统架构；其余流程按依赖层级布局。
- 分层布局使用正交连线、分组底色与标题，输出限制 60 节点 / 140 连线 / 3200×4800 像素。
- 渲染完全本地完成，不加载浏览器、脚本或网络资源。

## 0.6.0

- 新增文本转 HTML、Markdown 文件工具，可选文件名，发送到当前群聊或私聊。
- 文件导出代码归属 text 插件；HTML 支持 Markdown/纯文本排版，MD 保留原文。
- 文件发送沿用现有交付守卫与送达记录，不确定响应不自动重试。

## 0.5.0

- 统一中英文代码字体基线，使用整数像素网格和字形缓存，避免逐字抗锯齿相位差造成视觉抖动。
- 代码块独立渲染：等宽字体、中文回退、语法高亮、语言标签与原始行号。
- 长行保留缩进并标注续行，优先避免拆开标识符；未知语言安全降级为纯文本。

## 0.4.0

- 重排 Markdown 标题、段落、悬挂列表与表格，使用连续白底文档样式。
- 加粗优先使用系统粗体，正文默认 24px，代码块改为深色底。
- 英文单词优先整体换行；长图按实际页面高度拼接，不裁剪页边内容。

## 0.3.0

- 多页渲染结果纵向合并为单张长图，通过一条图片消息发送。

## 0.2.0

- 图片工具默认使用 Markdown 排版，保留 `format=plain` 纯文本模式。
- 支持标题、加粗、列表、引用、代码、表格、链接文字及删除线，长内容自动分页。
- 不执行 HTML，不加载本地或远程图片；图片显示替代说明。

## 0.1.0

- 新增六项仅供智能体使用的本地文本工具。
- 文本图片通过宿主媒体投递流程发送，沿用现有权限与会话失效检查。
