# 文本工具（text）

随 FLLBot 内置加载，只提供智能体工具，不注册聊天命令。
在管理后台授权所需工具；仍受现有插件开关、全局工具授权和会话策略控制。

| 工具 | 用途 |
| --- | --- |
| `text__render_image` | Markdown 或纯文本渲染成长图，自动分页并拼成一张图片发送到当前会话 |
| `text__statistics` | 字符、非空白字符、行、汉字与英文单词统计 |
| `text__transform` | 空白清理、删除空行、按行去重/排序、大小写、NFKC 规范化 |
| `text__replace` | 全部字面值替换，返回匹配次数 |
| `text__format_json` | JSON 校验、美化、压缩 |
| `text__codec` | UTF-8 Base64、URL 百分号、HTML 实体编解码 |

例如向智能体说“把这段说明做成图片发出来”“这些名单按行去重”“美化这段 JSON”。
除了图片工具会发送消息，其他工具仅返回处理结果给智能体。
智能体按场景决定是否发图片：短回复、简单列表、代码片段及仅需解释/总结时用普通文字；
较长且层次清楚、放在聊天气泡里难读的内容（例如多个小节、粗体标签与多组项目符号）可排成图片。
Markdown 符号本身不是转图理由；用户明确要图片时遵照用户要求。用户要简短总结时，直接提供总结。
决定使用图片时，智能体应先完成整段答复，再一次性渲染；不要拆成多张分段图片，也不要在图片之后重复发送全文。

每次输入和文本输出最多 30000 字符；超限返回错误，不截断原文。
图片最多 20 页、每页最高 1800 像素；分页会纵向拼成一张长图，以一条图片消息发送，避免多张图刷屏。图片完全在本地生成。
图片工具默认 `format=markdown`：支持标题、加粗、删除线、列表、引用、行内代码、代码块、分隔线、表格和链接文字。
选择 `format=plain` 可逐字显示 Markdown 符号。HTML 始终作为文字显示；图片仅显示替代说明，不读取本地图片、不下载远程资源。
表格最多 12 列，列宽不足时返回错误；长表格和长代码块可跨页，代码不做语法高亮。
排版依赖 Pillow 和 markdown-it-py（随项目安装）；后台可设置 `font_path`、`font_size`、`image_width`。
留空字体路径时自动查找 Windows 微软雅黑/黑体、Linux Noto CJK/文泉驿、macOS 苹方。
Linux 如无中文字体，需先安装中文字体或指定已有字体文件，否则返回明确错误。
字体中的缺失字形（如部分 Emoji）取决于所选字体，不保证彩色表情排版。

行去重按原文精确比较，保留首次出现的行；排序使用 Unicode 顺序。
NFKC 规范化可能改变兼容字符，请仅在需要统一字符形式时使用。
JSON 格式化遵循标准 JSON 解析行为，同名键只保留最后一个值，不适合需保留重复键的原始资料。
