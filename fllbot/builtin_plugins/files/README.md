# QQ 文件读取

仅提供智能体工具 `files__read_file`，不注册命令。授权后，用户可发送或引用一个文件消息并要求分析。
只读取当前消息或同会话直接引用消息中的文件，不接受模型指定本地路径、下载 URL 或任意文件 ID。

第一版支持 C#、Python、JavaScript、JSON、Markdown 等文本源码与配置文件，识别 UTF-8、带 BOM 的 UTF-16 和 GB18030。
最大 1 MB，每次返回 12000 字符，通过 `next_offset` 续读。附件仅作为分析资料，不执行文件代码。
NapCat 返回的本地下载路径仅适用于与 FLLBot 共用文件系统的部署；不同主机需返回 Base64 或可用的 QQ 公网下载链接。
暂不支持压缩包、PDF 和 Office 文件，也不读取转发记录深处的附件；请直接引用包含文件的原消息。
