# reminder

定时提醒：`/remind 10m 喝水`，到点由后台循环把提醒发回原会话。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/remind <时长> <内容>` | 创建提醒 |
| `/提醒 <时长> <内容>` | 中文别名 |
| `/remind list` | 查看当前会话的待提醒 |
| `/remind del <编号>` | 删除提醒（创建者或群管理员） |

## 时长格式

`30s`、`10m`、`2h`、`1d`，也接受 `分`、`分钟`、`小时`、`天`、`周`。只写数字时按分钟。
允许范围：10 秒 ~ 30 天。

## 示例

```text
> /remind 10m 喝水
好，#3，10 分钟后提醒：喝水

> /remind 2h 开会
好，#4，2 小时后提醒：开会
```

## 配置

| 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `max_per_scene` | int | `20` | 每个会话最多待提醒数 |
| `allow_private` | bool | `true` | 是否允许私聊提醒 |
| `text_template` | string | `【提醒 #{id}】{content}` | 提醒前缀模板 |

## 说明

- 提醒存在 SQLite 里，重启后不会丢
- 触发后自动删除；删除不存在的编号会提示
- 不支持重复提醒（cron），需要的话可以组合 `on_loop` 自己写
