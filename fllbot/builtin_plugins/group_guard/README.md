# group_guard

群治理：入群欢迎、退群提示、违禁词、刷屏检测，支持按群单独配置。

## 行为

- **入群欢迎**：新成员入群时发送欢迎语，模板支持 `{nickname}`、`{user_id}`、`{group_id}` 占位符
- **退群提示**：成员离开时提示（默认关闭）
- **违禁词**：命中后按配置的动作处理（撤回、撤回并禁言等）；每条以 `re:` 开头时按正则匹配
- **刷屏检测**：在时间窗口内超过条数阈值时触发，可配置禁言时长与通知管理员

## 命令

| 命令 | 说明 |
| --- | --- |
| `/guard` | 查看当前群的治理配置 |
| `/群管` | 中文别名 |
| `/welcome on` `/welcome off` | 开关入群欢迎 |
| `/welcome set <模板>` | 设置欢迎语 |
| `/badword` | 查看违禁词 |
| `/badword add <词>` | 添加违禁词 |
| `/badword del <词>` | 删除违禁词 |
| `/badword clear` | 清空违禁词 |

## 示例

```text
> /welcome set 欢迎 {nickname} 加入 {group_id} 群～
欢迎语已更新

> /badword add 广告
已添加违禁词：广告（共 1 个）
```

## 配置

共 12 项，可在「插件管理 → FLLBot 插件 → group_guard → 配置」里改，也可以切到「群 N」做单独覆盖：

- 欢迎 / 退群：开关、模板
- 违禁词：列表、命中动作、是否通知管理员
- 刷屏：开关、统计窗口、条数阈值、处理动作、禁言时长

## 说明

- 管理命令需要群管理员或 `superuser`
- 群级配置优先于全局默认，面板里只提交改动过的字段
- 违禁词建议先用 `/badword` 看当前列表，避免重复添加
