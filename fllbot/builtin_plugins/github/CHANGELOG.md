# 变更记录

## 0.5.0

- 图片卡片改用**真实 GitHub 头像**：贡献者、Issue/PR 作者与评论者、仓库所有者、提交作者都会加载头像；
  只允许 `avatars.githubusercontent.com`，单张不超过 512 KB，取 96px 版本，失败时回退首字母色块。
- 新增本地矢量图标库 `icons.py`：星标、Fork、Issue、PR、合并、草稿、提交、分支、标签、文件夹、
  文件、代码、图片、压缩包、评论、时钟、日历、下载、盾牌、勾选等，全部由 Pillow 绘制，不依赖字体或图片资源。
- 卡片排版升级：顶部代码徽标、分区图标与细线、带图标的统计标签、按语言着色的文件类型徽标、
  前三名金/银/铜排名、头像列表行；标题改用真实粗体字体（找不到时再模拟描边）。
- `read_contributors`、Issue/PR 列表、Issue 详情、提交与仓库概览新增头像字段；
  `fetch_avatars` 负责校验主机、限制大小、并发下载并缓存（进程内 1 天，最多 128 张）。
- 新增头像下载、渲染与图标相关测试；README 与开发说明同步。

## 0.4.0

- 新增 `render_card`：插件自己读取仓库数据并在本地渲染成中文图片卡片发送，不再依赖 text 插件的通用排版。
  支持仓库概览、贡献者榜单、Issue/PR 列表、Issue 详情、提交改动、版本与分支八种卡片。
- 新增 `font_path` 配置：指定卡片中文字体，留空自动探测系统字体；渲染不下载头像或图片、不访问图片 URL。
- 卡片样式：GitHub 浅色主题、状态标签、统计条、贡献者首字母头像与提交占比条、文件改动列表；
  贡献者最多 30 行、Issue/PR 15 行、改动文件 15 个、评论 4 条，宽度 720–1200（默认 960）。
- 插件依赖声明补充 `Pillow`；新增渲染与发送测试，覆盖八种卡片、空数据与错误参数。

## 0.3.0

- 新增 `read_contributors`：GitHub 官方贡献者榜单（账号、主页、提交数、类型），可选包含匿名提交；
  接口返回 202 时明确标记 `state=pending`，不再让模型自行猜测或改用网页抓取。
- 新增 `read_issues`、`read_pull_requests`：Issue/PR 列表，支持状态、排序、标签过滤与翻页；
  Issue 列表自动过滤 PR 并报告过滤数量，避免“Issue 全是 PR”。
- 新增 `read_issue`：单个 Issue/PR 的正文、标签、状态与最近评论（按最后一页读取），
  PR 附带合并状态、增删行数、改动文件数与分支。
- 新增 `read_commit`：单次提交的说明、作者、增删统计与文件补丁；补丁按单文件/单次预算截断，
  `ref` 留空读取最新提交，分支名含 `/` 时先解析成 SHA。
- 新增 `read_branches`：分支列表、受保护标记、最新提交短 SHA 与默认分支。
- 新增 `search_code`：在指定仓库内按关键字搜索代码，返回路径、链接与命中片段；需要配置只读令牌，
  `repo:` 由插件自动限定，命中片段通过 `text-match` 媒体类型获取并计入搜索额度。
- `_request` 支持空响应体（202/204），供贡献者统计中、空仓库等场景给出准确说明。
- 缓存不再保存空响应；补充新工具的测试、README、开发说明与提交/讨论预算。

## 0.2.0

- 新增 `list_directory`：按目录逐层浏览并对大目录分页，替代只能依赖 400 条全量文件树的旧方式。
- 新增 `search_repositories`：按关键词与 GitHub 限定符检索公开仓库。
- 新增 `read_releases`、`read_commits`：确认版本、更新说明、最近维护状态与单文件改动时间。
- `read_repository` 增加 `ref`、`tree_path`、`offset`/`limit`，返回语言/主题/许可证/推送时间等元信息。
- `read_repository` 新增 `view=tree` 缩进结构树：`depth` 控制层数（1–4），`tree_path` 展开子树；
  超过 200 行时自动退回完整顶层结构，结构树含图片、`paths` 只列可读文本。
- `read_sources` 支持 `ref` 与 `path#L10-L40` 行范围，返回 `total_lines`/`next_line` 继续读取。
- 新增只读结果缓存（默认 180 秒）与令牌/速率/次要限流分类错误提示，降低 API 额度消耗。
- 文件清单过滤生成目录并按源码/文档优先排序；输出按预算裁剪，避免触发宿主的 JSON 截断。
- 新增 `timeout`、`cache_seconds` 配置项；README 与开发文档同步更新。

## 0.1.0

- 新增只读 GitHub 仓库读取工具：仓库元信息、README、文件清单、图片清单及指定文本文件。
- 新增按批次读取源码工具，支持针对目录撰写有源码依据的详细技术分析。
