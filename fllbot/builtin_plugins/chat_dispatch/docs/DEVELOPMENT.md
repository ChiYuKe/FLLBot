# 开发说明

插件通过 `Plugin.chat_dispatch` 提供模型提示和合并判断。宿主将单条消息长度传给插件，并在构建普通消息发送计划时提供实际分段数。

模型在正常回复中给出首行发送标记。宿主解析标记、清理正文、检查会话权限并发送消息。模型判断和正文共用一次生成请求。

宿主在构建提示和发送时分别读取插件启用状态。用户要求直接发文字、临时私聊，以及合并转发被明确拒绝后的补发，由宿主按对应场景处理。

工具调度提示基于已筛选的工具定义。`workflows.py` 记录各插件之间容易混淆的职责，具体参数和操作限制来自工具的注册描述。工具执行器继续负责沙盒和即时权限复核。对同轮、同工具、同参数的 QQ 消息、附件或邮件交付，执行器检查已持久化的执行事实，复用已确认结果，并拦截正在执行或结果不确定的重复调用。
