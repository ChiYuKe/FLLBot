# 更新记录

## 0.2.0

- 新增游戏中文翻译（.po）索引：把「电解器」「净水器」这类中文显示名展开成
  `Electrolyzer`、`WaterPurifier` 等代码标识符，检索结果附带 `translated_terms` 与 `translations`。
- 新增插件设置 `strings_file`，可填简体中文 .po 文件或 `StreamingAssets/strings` 目录；
  文件缺失、损坏或超过 64 MB 时退回原有中文别名表，不影响源码检索。
- 翻译文件按修改时间缓存解析结果，只在首次检索时读取，不阻塞后续请求。

## 0.1.0

- 添加类型/成员检索、中文功能词扩展、只读源码分页和引用位置。
- 通过插件策略接入 Agent 自主检索与现有图片排版工具。
- 限制目录范围、索引文件类型和结果长度；不执行知识库中的脚本。
