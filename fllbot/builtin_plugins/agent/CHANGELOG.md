# 更新记录

## 0.4.0

- 新增全局（非群级）设置 `private_enabled`（默认关闭）与 `private_allowed_tools`（默认空）：
  私聊需单独开启并逐项授权工具，群聊设置与群级覆盖不受影响。
- 私聊按场景走完整 Agent：`scene=private`、`scene_id=对方 QQ`，读取私聊历史，模型、额度与人格沿用
  Bot 默认和全局聊天配置；私聊消息视为明确请求，不做自动参与评分，也不提供 `agent__stay_silent`。
- 场景隔离：群历史与群记忆（含摘要、`agent__search_history`）不进入私聊上下文，私聊历史也不进入群聊；
  群级策略与单群沙盒覆盖不作用于私聊，私聊按全局 `[sandbox]` 裁决并使用 `private_<QQ>` 工作区。
- 私聊支持 `/任务进度`、`/任务取消`、`/任务补充` 与执行中直接追问，结果沿用私聊分段、合并转发或长图发送。
- 管理端“配置 → 默认行为 → 私聊智能体”可编辑开关与工具选择，保存后对下一条私聊消息生效；
  消息追踪补充 `private_disabled`、`private_trigger_matched` 等私聊原因码。

## 0.3.0

- 改用宿主 `ToolRegistry` 快照生成工具列表：只为入选工具复制 Schema，工具定义模板跨轮复用。
- 执行阶段只解析目标工具并实时复核群授权/插件开关/权限，不再重建整份工具目录。
- 同一轮内相同参数的纯读取工具调用由执行器复用结果，减少重复 I/O。

## 0.2.0

- 新增 `participation_threshold`：自动参与先做确定性评分，低于阈值不请求模型；可单群覆盖。
- 回查本群记忆工具声明 `memory.read` 能力，由宿主沙盒统一裁决。

## 0.1.0

- 迁移为独立目录插件包，保留原有命令、配置、权限和 AI 工具名称。
