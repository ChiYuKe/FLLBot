# 更新记录

## 0.3.0

- 改用宿主 `ToolRegistry` 快照生成工具列表：只为入选工具复制 Schema，工具定义模板跨轮复用。
- 执行阶段只解析目标工具并实时复核群授权/插件开关/权限，不再重建整份工具目录。
- 同一轮内相同参数的纯读取工具调用由执行器复用结果，减少重复 I/O。

## 0.2.0

- 新增 `participation_threshold`：自动参与先做确定性评分，低于阈值不请求模型；可单群覆盖。
- 回查本群记忆工具声明 `memory.read` 能力，由宿主沙盒统一裁决。

## 0.1.0

- 迁移为独立目录插件包，保留原有命令、配置、权限和 AI 工具名称。
