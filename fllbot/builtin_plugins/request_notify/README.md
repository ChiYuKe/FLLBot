# request_notify

好友申请、入群邀请的即时提醒，并支持超级管理员在聊天里直接处理。

## 行为

- 收到 `request` 事件时，给所有 `bot.superusers` 发私聊提醒，带申请人和验证信息
- 每个请求生成一个短标记（flag），用于后续同意/拒绝

## 命令

| 命令 | 说明 |
| --- | --- |
| `/requests` | 列出待处理的请求 |
| `/请求` | 中文别名 |
| `/approve <标记>` | 同意该请求 |
| `/agree` `/通过` | 别名 |
| `/reject <标记> [理由]` | 拒绝该请求 |
| `/拒绝` | 中文别名 |

## 示例

```text
> /requests
待处理请求：
1. [friend] 用户 12345678：求通过
   标记：abc123

> /approve abc123
已同意 friend / 12345678
```

## 说明

- 所有命令仅 `superuser` 可用
- 处理过的请求会从列表移除，重复操作会提示「没有找到该请求」
- 需要机器人能接收 `request` 上报（NapCat 默认开启）
