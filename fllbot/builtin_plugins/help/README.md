# help

列出当前已加载插件提供的命令，以及插件启停状态。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/help` | 按插件分组列出所有命令 |
| `/帮助` `/菜单` `/commands` | 别名 |
| `/plugins` | 列出插件名称、版本与启用状态 |
| `/插件` | 别名 |

## 示例

```text
> /help
可用命令：

[ping] 连通性测试：确认机器人是否在线
  /ping（别名 /在吗、/pong）

[echo] 把你说的话原样复读一遍
  /echo（别名 /复读、/repeat）
```

## 说明

- 只列出已加载插件的命令，停用的插件仍会显示（状态见 `/plugins`）
- 命令前缀跟随 `bot.command_prefix`
