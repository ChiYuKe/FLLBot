# daily 日常助手

元信息见 [plugin.toml](plugin.toml)。提供提醒与待办、群资料库、成员查询和引用消息读取。

## 使用

插件随 `plugins/` 目录自动发现。在 WebUI 的群聊设置中，为 Agent 勾选所需工具，模型须支持工具调用。
网页总结使用已有 web 插件的 `web__read_webpage`，无需重复安装。无额外依赖、密钥或配置。

| 工具 | 示例 |
| --- | --- |
| `daily__create_task` | 明晚八点提醒我交作业；把买牛奶加入待办 |
| `daily__list_tasks` | 看看我的待办和提醒 |
| `daily__update_task` | 完成第 3 项；取消第 5 项提醒 |
| `daily__search_knowledge` | 查一下本群服务器地址 |
| `daily__save_knowledge` | 保存群资料：服务器地址是…… |
| `daily__delete_knowledge` | 删除标题为「旧群规」的资料 |
| `daily__find_members` | 查一下昵称含小明的群成员 |
| `daily__read_reply` | 引用消息后询问：这条消息说了什么？ |

## 权限与数据

提醒和待办只允许操作本人在当前会话的数据，并按机器人账号隔离；单会话每人最多 100 条未完成事项。
群资料仅当前群管理员或超级用户可以维护，所有成员可查询；每群最多 500 条。
群成员查询只返回 QQ、昵称、名片和身份。引用读取仅接受当前消息直接引用的 ID，
并检查返回消息所属会话；NapCat 未返回可验证群号时会拒绝读取。
私聊引用仅支持可确认由当前用户发送的消息。图片、语音等返回占位说明，不自动识别附件。

提醒使用 ISO8601 时间，无时区时按北京时间 UTC+08:00；每 15 秒检查一次。
机器人离线或群/插件关闭时等待，每分钟重新检查，条件恢复后补发。发送报错或中断且未取得回执时标记为“送达不确定”，停止自动重试。
成功提醒后事项仍保留为未完成，用户可以显式完成或取消。
发送前先持久化发送中状态及运行记录；重启或插件重载会将遗留的发送中状态恢复为送达不确定。管理员可在任务中心明确确认重复发送风险后允许重试，执行前仍重新检查权限与连接。不能承诺平台端恰好送达一次。
提醒发送无需再次调用模型。插件移除后不再执行；停用时保留任务与记录，等待条件恢复。

数据保存在 `data/plugins/daily/daily.sqlite3`；备份时需包含此目录。没有单独命令，创建事项通过 Agent 使用；后台任务中心支持筛选、运行记录及暂停/恢复/取消/完成/受控重试。主数据库备份不包含这个插件数据库。
工具授权仍由宿主按群控制，启用插件后也需勾选相应工具。
