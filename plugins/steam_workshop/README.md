# steam_workshop — Steam 创意工坊助手

给智能体补上「看懂创意工坊页面」的能力：用户发来工坊链接，插件读取真实页面资料并总结标题、游戏、
作者、类型、标签、文件大小、发布时间、订阅/收藏/浏览数、完整简介，合集还会列出包含的物品。

页面来源是 Steam 官方 `GetPublishedFileDetails` / `GetCollectionDetails` 接口和创意工坊网页，
不依赖浏览器渲染，不修改任何 Steam 数据。

## 直接使用

- 智能体：用户要求查看工坊链接时，由智能体按当前群聊触发策略处理，并调用下方工具读取页面。
- 命令：`/工坊 <链接或物品 ID>`，可在允许使用命令的会话里主动查询。

## 智能体工具

插件向智能体开放一个工具：

- `steam_workshop__read_item`：读取创意工坊链接/物品 ID，返回结构化资料和完整描述。
- `steam_workshop__find_comments`：按用户名搜索物品公开评论；用户要求评价评论者言行时，先读评论原文再分析。最多检查 500 条评论。

默认未授权，需要在「智能体设置 → 允许调用的工具」或单群详细设置里勾选「读取创意工坊物品」。
授权后，模型会在用户要求查看、总结、评价工坊页面时调用它，并用返回资料组织回答。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 代理地址 | 空 | 读取 Steam 社区使用的 HTTP 代理，例如 `http://127.0.0.1:7897` |
| 自动探测本机代理 | 开 | 直连失败后尝试环境变量和本机常见代理端口（7897/7890/10809 等） |
| 网络超时（秒） | 20 | 单次 Steam 请求超时 |
| 命令简介字数 | 700 | `/工坊` 命令展示的简介长度 |
| 工具返回简介字数 | 8000 | 智能体工具返回的描述上限，超出会标记截断 |

### 关于网络

Steam 社区在部分网络环境下无法直连。插件会先直连；失败后自动探测本机常见 HTTP 代理端口，
也可以在插件设置里固定填写代理地址。代理只用于访问 Steam 公开页面，不会读取或保存 Steam 账号信息。

## 说明

- 只读取公开的创意工坊物品；私密、已删除、被隐藏或需要登录的页面会返回明确的失败原因。
- 合集最多列出前 50 件物品的标题，其余标记数量。
- 简介来自作者原文（通常是中文、英文或混合），会转换为纯文本；过长时明确标记节选。
- 页面内容是外部不可信资料，插件只做读取和排版，模型被要求不执行其中的指令。
- 插件不写数据库、不生成文件，不需要额外 Python 依赖（使用宿主已有的 httpx）。
