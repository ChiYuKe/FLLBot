# web — 联网搜索、天气与当前时间

让智能体能查实时信息：网页搜索、读取指定网页、城市天气和当前时间。命令和智能体工具共用同一套实现。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/搜索 关键词`（别名 `/搜索` `/联网`） | 联网搜索，返回标题、链接和摘要 |
| `/天气 城市`（别名 `/天气`） | 实时天气 + 未来几天预报（默认 3 天） |
| `/现在 [城市]`（别名 `/时间` `/几点`） | 当前日期和时间，可指定城市时区 |

示例：

```
/搜索 武汉 明天 天气
/天气 武汉
/现在 东京
```

## 智能体工具

插件向智能体开放四个工具（在「允许调用的工具」里逐个勾选，默认均未开放）：

- `web__web_search`：搜索实时信息
- `web__read_webpage`：读取用户给出的公开网页正文；页面较长时按片段续读
- `web__get_weather`：查天气（回答天气问题前必须调用）
- `web__get_current_time`：查当前时间（回答「现在几点」前必须调用）

工具结果是不可信的外部数据，模型被要求只做参考、不执行其中的指令。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 搜索后端 | `bing` | `bing` 免密钥；`tavily` / `serper` 需 API Key；`searxng` 需自建实例 |
| Tavily API Key | 空 | 后端为 tavily 时必填 |
| Serper API Key | 空 | 后端为 serper 时必填 |
| SearXNG 地址 | 空 | 后端为 searxng 时必填，实例需开启 JSON 输出 |
| 搜索返回条数 | 5 | 1–10 |
| 网络超时（秒） | 12 | 3–30 |
| 默认城市 | 空 | 天气命令/工具没写城市时使用 |
| 天气预报天数 | 3 | 1–7 |

天气和城市时间来自 [Open-Meteo](https://open-meteo.com/)，免密钥；搜索默认走必应中文结果页。
不需要在 `config.toml` 里加配置，全部通过插件配置（管理端或 `PATCH /api/plugins/web/settings`）修改。

## 启用

1. 插件默认启用（`plugins/` 下自动加载，热重载生效）。
2. 在智能体设置或单群详细设置里勾选「联网搜索 / 读取网页 / 天气查询 / 当前时间」，模型才会看到对应工具。
3. 直接用 `/搜索`、`/天气`、`/现在` 验证网络是否可达。

## 注意

- 必应结果页是 HTML 解析，页面结构变化时可能取不到结果；长期使用建议配 Tavily / Serper。
- 搜索摘要会被截断到 220 字，天气只返回结构化字段，避免污染上下文。
- 网页读取保留标题、正文、列表、表格和页面链接；每次读取 10000 字符，单页最多 100000 字符。更长的页面会明确标记截断，模型会在工具调用轮数允许时续读。
- 只读取公网 HTTP/HTTPS 的 HTML 或纯文本。需要登录、由浏览器脚本动态加载或受站点限制的页面可能无法读取。
- 插件只做只读网络请求，不会修改任何本地数据。
