# web — 联网搜索、天气与当前时间

让智能体能查实时信息：网页搜索、读取指定网页、城市天气和当前时间。命令和智能体工具共用同一套实现。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/搜索 关键词`（别名 `/搜索` `/联网`） | 联网搜索，返回标题、链接和摘要 |
| `/天气 城市`（别名 `/天气`） | 实时天气 + 未来几天预报（默认 3 天），默认回复一张天气卡片图 |
| `/现在 [城市]`（别名 `/时间` `/几点`） | 当前日期和时间，可指定城市时区 |

示例：

```
/搜索 武汉 明天 天气
/天气 武汉
/天气 杭州市
/现在 东京
```

天气默认来自腾讯 QQ 天气（`wis.qq.com`，免密钥、国内直连），只覆盖国内城市；城市名可带「市 / 区 / 县」后缀。
在「天气服务」里可以切回 Open-Meteo（覆盖全球，但部分网络环境连不上）。

天气卡片是本地 Pillow 排版的 900px PNG，样式参考 QQ 天气：深色天气场景（雨丝、星空、城市剪影），
顶部是城市和风力/湿度/空气质量，右侧是大温度与今日高低温，下面依次是「今日天气」逐小时、
「生活指数」8 项和「未来 N 天」逐日预报。QQ 天气模式会取逐小时与 8 项生活指数；切到 Open-Meteo
或接口缺字段时，这两块自动省略，卡片缩成逐日预报。渲染失败或关闭「天气卡片图片」后自动退回纯文字。
QQ 天气不提供体感温度和逐日降水概率，这两项会直接从卡片和文字里省略，不会显示占位符。

## 智能体工具

插件向智能体开放五个工具（在「允许调用的工具」里逐个勾选，默认均未开放）：

- `web__web_search`：搜索实时信息
- `web__read_webpage`：读取用户给出的公开网页正文；页面较长时按片段续读
- `web__get_weather`：查天气，返回结构化文字数据（回答天气问题前必须调用）
- `web__weather_card`：查天气并直接发送一张天气卡片图片，同时返回相同的数据
- `web__get_current_time`：查当前时间（回答「现在几点」前必须调用）

`web__weather_card` 声明了 `net.read` 与 `qq.send`，自动参与或沙盒关闭发送时会被拒绝，此时模型会说明限制。
工具结果是不可信的外部数据，模型被要求只做参考、不执行其中的指令。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 搜索后端 | `bing` | `bing` 免密钥；`tavily` / `serper` 需 API Key；`searxng` 需自建实例 |
| Tavily API Key | 空 | 后端为 tavily 时必填 |
| Serper API Key | 空 | 后端为 serper 时必填 |
| SearXNG 地址 | 空 | 后端为 searxng 时必填，实例需开启 JSON 输出 |
| 搜索返回条数 | 5 | 1–10 |
| 网络超时（秒） | 12 | 3–30 |
| 天气服务 | `qq` | `qq` 为腾讯 QQ 天气（国内直连，仅国内城市）；`open-meteo` 覆盖全球但可能连不上 |
| 默认城市 | 空 | 天气命令/工具没写城市时使用 |
| 天气预报天数 | 3 | 1–7 |
| 天气卡片图片 | 开 | `/天气` 直接回复卡片图；关闭则只回文字 |
| 天气卡片字体 | 空 | 留空自动查找系统中文字体；Linux 可填 TTF/OTF/TTC 绝对路径 |

天气默认来自 [腾讯天气（QQ 天气）](https://tianqi.qq.com/)，不需要密钥；切到 Open-Meteo 时数据来自 [open-meteo.com](https://open-meteo.com/)。
搜索默认走必应中文结果页。不需要在 `config.toml` 里加配置，全部通过插件配置（管理端或 `PATCH /api/plugins/web/settings`）修改。

## 启用

1. 插件默认启用（`plugins/` 下自动加载，热重载生效）。
2. 在智能体设置或单群详细设置里勾选「联网搜索 / 读取网页 / 天气查询 / 当前时间」，模型才会看到对应工具。
3. 直接用 `/搜索`、`/天气`、`/现在` 验证网络是否可达。

## 注意

- 必应结果页是 HTML 解析，页面结构变化时可能取不到结果；长期使用建议配 Tavily / Serper。
- 搜索摘要会被截断到 220 字，天气只返回结构化字段，避免污染上下文。
- 天气卡片完全在本地用 Pillow 排版，不加载网页或远程图片，也不需要额外密钥；图片只在聊天里发送，不占用模型上下文，按群可关闭。
- QQ 天气只覆盖国内城市：`/天气 Tokyo` 会提示改用中文城市名；需要国外城市时把「天气服务」切到 Open-Meteo。
- QQ 天气的观测值来自城市观测站，可能和逐日预报的天气描述不完全一致（例如现在“雨”、今天预报“小雨”），属正常现象。
- 网页读取保留标题、正文、列表、表格和页面链接；每次读取 10000 字符，单页最多 100000 字符。更长的页面会明确标记截断，模型会在工具调用轮数允许时续读。
- 只读取公网 HTTP/HTTPS 的 HTML 或纯文本。需要登录、由浏览器脚本动态加载或受站点限制的页面可能无法读取。
- 插件只做只读网络请求，不修改任何本地数据。
