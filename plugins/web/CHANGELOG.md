# 更新记录

## 0.4.0

- 天气卡片改为 QQ 天气风格：深色天气场景（雨丝、星空、城市剪影）、顶部城市 + 风力/湿度/空气质量、
  右侧大温度与今日高低温；下方依次是「今日天气」逐小时、「生活指数」8 项和「未来 N 天」逐日预报。
- QQ 数据源新增 `forecast_1h` 与 `index`：逐小时按时间排序并只取当前小时之后的 7 段；生活指数按
  晾晒/运动/晨练/紫外线/过敏/穿衣/化妆/感冒的顺序取 8 项。文字天气同步增加「生活指数」一行。
- 新增夜晚多云图标（月牙 + 云），逐小时跨到夜间时不再显示太阳。

## 0.3.0

- 天气默认改用腾讯 QQ 天气（`wis.qq.com`）：国内直连、免密钥，城市名支持「武汉市 / 杭州市」等带后缀写法；
  仍可在「天气服务」里切回 Open-Meteo（覆盖国外城市）。
- 新增动作：`weather_type` 同时取观测、逐日预报、空气质量和日出日落；预报里的“昨天”会被过滤。
- 天气卡片与文字适配 QQ 字段：不再假设有体感温度和逐日降水概率，缺失时隐藏对应条目，改为展示风力、
  空气质量和日出日落；`run_weather` 结果新增 `source`、`sunrise`、`sunset`、`air`。
- `/现在 城市` 在 QQ 天气模式下按北京时间返回，不再依赖 Open-Meteo 是否可达。

## 0.2.0

- 新增天气卡片图：`/天气` 默认回复一张 900px 宽的 PNG 卡片，包含实时天气、体感、湿度/降水/风速和未来几天预报，按天气与昼夜切换配色，图标由 Pillow 几何绘制，不依赖外部素材。
- 新增智能体工具 `web__weather_card`：查天气后直接发送卡片图，只做文字查询时仍用 `web__get_weather`；两者共用同一套数据。
- 新增配置「天气卡片图片」「天气卡片字体」；渲染失败或关闭图片时自动退回原来的文字天气。
- `run_weather` 的 `current` / `daily` 增加天气代码 `code`，供卡片选择图标和主题。

## 0.1.0

- 迁移为独立目录插件包，保留原有命令、配置、权限和 AI 工具名称。
