# poke — QQ 戳一戳

把 QQ 的「戳一戳」做成独立插件：别人戳机器人时按当前人格回应、可选自动回戳，并允许智能体在聊天里主动戳人。

## 使用前提

1. NapCat 支持并上报 `notice.notify.poke`，且群里有戳一戳入口。
2. 已配置模型服务；被戳回应走群聊模型回复，因此还需要该群允许群聊 AI（`[llm].enable_group`，默认开启）。
3. 在「插件」页启用 `poke`。

插件不依赖内置 `agent`；即使关闭智能体，被戳回应和回戳仍然可用。主动戳人的工具需要 `agent` 提供工具调用能力。

## 被戳时

群友双击头像或使用群戳一戳后，插件会：

1. 按「回戳」设置先戳一下发起者（可关）；
2. 把事件包装成一条群聊上下文「戳了你一下」，附上戳人者群名片；
3. 通过 `ctx.llm` 走正常的群聊回合，按当前人格生成一到两句回复，并写入群聊历史。

只处理「别人在群里戳机器人」：私聊戳、群友互戳、机器人自己发起的戳都会忽略。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 被戳一戳时回应 | 开 | 关闭后只回戳或不处理 |
| 被戳时戳回去 | 开 | 回应前先回戳发起者 |
| 戳一戳回应冷却 | 10 秒 | 同一群两次回应之间的最小间隔，0 为不限制 |
| 回戳冷却 | 10 秒 | 对同一人两次自动回戳的最小间隔，0 为不限制 |

以上设置都支持单群覆盖。冷却内的戳不会调用模型，也不会重复回戳。

被戳回应只看群聊模型回复开关（`[llm].enable_group` 与群级 LLM 覆盖），不依赖 `agent` 的
「群聊自然语言响应」；如果只想让部分群回应，在这些群里把「被戳一戳时回应」关掉即可。

## 智能体工具

| 工具 | 说明 |
| --- | --- |
| `poke__poke` | 在当前会话戳指定群成员；省略 `user_id` 时戳当前发言者 |

- 需要在「允许调用的工具」或单群设置里勾选后模型才能看到。
- 声明 `qq.send` 能力，属于写操作；自动参与（没人明确叫机器人）时宿主会拒绝执行。
- 只限当前群聊，不支持跨群；同一目标 5 秒内只戳一次，避免模型连续刷戳。

示例请求：

```
戳一下他
帮我戳 @小明 提醒他看群
```

## 限制

- 私聊戳暂不处理。
- 戳事件没有消息 ID 和昵称，插件会用 `get_group_member_info` 补查昵称，失败时退化为 QQ 号；结果缓存 10 分钟。
- QQ 对戳一戳有频率限制，失败只记录日志，不影响文字回复。
- 自动回戳带冷却；如果你的群里有多个会自动回戳的机器人，仍建议把回戳关掉或调大冷却。
